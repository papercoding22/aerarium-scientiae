# Aerarium Scientiae

Personal knowledge base for long-term learning, research, reference, and synthesis.

This repo is optimized for:

- learning ideas deeply
- finding facts and concepts later
- connecting ideas across domains
- applying knowledge to life, work, and business
- working well with Git, VS Code, and AI tools

## Start Here

Use this flow:

1. Capture quick notes in `inbox/`.
2. Create one source note in `sources/` for each book, article, paper, video, web page, or cleaned AI conversation.
3. Split important ideas into atomic concept notes under `knowledge/<domain>/concepts/`.
4. Put practical usage notes under `knowledge/<domain>/applications/`.
5. Collect flashcards and questions under `learning/`.
6. Write polished essays, research reports, and synthesis documents under `outputs/`.
7. Keep personal drafts and private thinking in `private/`, which is ignored by Git.

## Main Areas

```text
inbox/        Temporary capture and weekly processing.
knowledge/    Reusable concept and application notes, organized by domain.
sources/      One note per source, focused on what the source said.
learning/     Flashcards, questions, and weekly review notes.
outputs/      Essays, research reports, and synthesis documents.
templates/    Lightweight templates for new notes.
private/      Local-only private notes. Not committed to Git.
```

## Naming

Use lowercase kebab-case filenames:

```text
opportunity-cost.md
deep-work-cal-newport.md
```

No stable IDs are needed. Use clear filenames, headings, and normal Markdown links.

## Confidence

Use one of these confidence values:

```text
high
medium
low
needs-review
```

Confidence means how reliable or well-understood the note is, not how important it is.

## Weekly Review

Once per week:

- empty `inbox/`
- improve messy notes
- create or update concept notes
- connect related notes when useful
- update confidence levels
- add flashcards for ideas worth remembering
