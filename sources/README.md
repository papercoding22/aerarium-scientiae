# Sources

Use one note per source.

Source notes should capture what the source said, important highlights, extracted ideas, and concept notes created from the source.

## Source Types

- `books/`
- `articles/`
- `papers/`
- `videos/`
- `web-pages/`
- `ai-conversations/`

## Filename Style

Use lowercase kebab-case with enough context to identify the source:

```text
deep-work-cal-newport.md
attention-is-all-you-need-vaswani.md
```

Use [templates/source-note.md](../templates/source-note.md) for new source notes.
