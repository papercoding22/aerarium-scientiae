# Inbox

Use this folder for temporary capture.

Good inbox items:

- quick ideas
- copied highlights waiting for processing
- rough notes from reading or videos
- possible concepts to split later
- questions to investigate

During weekly review, move each useful item into:

- `sources/`
- `knowledge/<domain>/concepts/`
- `knowledge/<domain>/applications/`
- `learning/`
- `outputs/`

Put private drafts and personal notes in `private/`, not here.
